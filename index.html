Data konfirmasi akan disimpan ke Spreadsheet ID: 1ViRbaN_tNOPD4M8kNbwdxKEXYzhD4DVLn5MWf10KVsI pada tab Data2.

Petunjuk Pemasangan Cepat (1 Menit):
  1. Buka Spreadsheet > Menu Ekstensi > Apps Script.
  2. Ganti seluruh isi editor dengan kode dari file code.gs.
  3. Klik Deploy > New Deployment > Pilih jenis Web App.
  4. Atur Execute as: Me dan Who has access: Anyone.
  5. Salin URL Web App yang berakhiran /exec lalu tempelkan ke kolom input di atas.
